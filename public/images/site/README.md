# Photos du site public

Déposez ici vos photos, puis renseignez `src` dans `src/features/marketing/site-config.ts`.
Exemple : `heroMain: { tone: "night", src: "/images/site/hero-main.jpg" }`.

| Emplacement | Format conseillé |
|---|---|
| `heroMain` (grande photo centrale) | 1200 × 1400 px, portrait |
| `heroTopLeft`, `heroBottomLeft`, `heroTopRight`, `heroBottomRight` | 800 × 600 px |
| `levelA1` … `levelB2`, `skillReading` … `skillWriting` | 900 × 675 px (4:3) |
| `liveClass` | 1200 × 900 px (4:3) |

Utilisez des photos dont vous détenez les droits (vos étudiants avec leur accord, ou une banque d'images libre de droits).
